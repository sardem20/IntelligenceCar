# IntelligenceCar

Projeto organizado em duas partes: `frontend` em Flutter e `backend` em Flask.

## Estrutura

- frontend: telas e consumo da API
- backend/controllers: endpoints da API
- backend/services: casos de uso, um Service por funcionalidade
- backend/models: entidades e operações CRUD básicas
- backend/repositories: consultas específicas por procedures SQL
- backend/database: criação do banco e procedures

## Execução

Consulte os READMEs dentro de `frontend` e configure o `.env` do backend a partir de `.env.example`.
